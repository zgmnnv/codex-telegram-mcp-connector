# Работа над Telegram-ботом для Codex

- Используй Telegram Bot API и один привязанный личный чат. Codex работает на Маке владельца, в режиме чтения. Держи привязку и ключи на машине владельца.
- В меню показывай локальные активные чаты. Исключай архивные, служебные и делегированные сессии. Перед запуском повторно проверяй принадлежность чата выбранному проекту.
- Создание проекта и чата требует отдельного подтверждения. Голосовое отправляется на расшифровку по нажатию кнопки, а текст передаётся Codex после подтверждения.
- Коммить общий код и вымышленные тестовые данные. Исключай ключи, сессии, переписку, реальные имена проектов и агентов, идентификаторы локальных чатов и личные пути.
- Используй адрес GitHub noreply для автора и коммитера. Перед коммитом проверь список добавленных файлов. Выполни `node --test codex-bot/*.test.mjs` и `python3 scripts/check-staged.py`.
- Делай изменения в отдельных ветках и открывай PR после проверки diff, тестов и адресов автора и коммитера. В `main` сливает владелец репозитория.
- Для изменений бота используй [справочник проекта](.agents/skills/telegram-codex-macos/SKILL.md).
