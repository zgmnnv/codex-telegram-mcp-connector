# Telegram-бот для Codex на Маке

Личный чат с ботом связывает телефон с твоими локальными агентами Codex. Бот запускается на Маке и использует Telegram Bot API. [Подключить бота](START_HERE.md)

## Что умеет бот

- **Проекты и чаты.** Команда `/menu` показывает локальные проекты и пункт **Вне проектов**. В списках остаются активные чаты без архива и служебных сессий.
- **Модели.** Выбор сохраняется отдельно для каждого чата.
- **Новые проекты и чаты.** Введи название и подтверди кнопкой **Создать**. Проекты сохраняются в локальном Codex. Для проекта без привязанной папки чат использует рабочую папку запуска.
- **Задачи и статусы.** Текст продолжает выбранный чат. Ответ на результат продолжает чат этого результата. Команда `/status` показывает состояние задачи из Telegram.
- **Голосовые.** Нажми **✍️ Расшифровать**, проверь текст и нажми **Отправить в Codex**.

## Доступ и данные

Команды принимает один личный чат, привязанный кодом при первом запуске. Бот сам запрашивает обновления у Telegram. Задачи Codex запускаются с доступом к файлам на чтение и без повышения прав.

Названия чатов и ответы видны в Telegram. После нажатия кнопки расшифровки аудио обрабатывает выбранный сервис. Подтверждённый текст передаётся модели Codex. Ключи хранятся в Связке ключей macOS. Привязка чата и выбор моделей хранятся в локальной папке `private/`, исключённой из Git.
